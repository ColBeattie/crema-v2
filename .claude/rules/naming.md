# Naming Conventions

- Never write variables in another language than English.
- Always think about the names of the variables for the database and in the code. Think about what vocabulary the industry uses who this app is built for. If you're not sure, show suggestions to the user and let him decide before you continue.
- kebab-case for routes
- snake_case for DB columns and tables
- lowerCamelCase for code
- Singular table names for entities
- `_at` suffix for timestamps (e.g. `created_at`, `updated_at`)
- `_id` suffix for foreign keys (e.g. `user_id`, `organization_id`)
